# OpenGate VPN

Официальные сборки приложения **OpenGate VPN** для Windows, macOS, Linux и Android.

Скачайте последнюю версию на странице **[Releases](https://github.com/OpenGateTeam/opengate-vpn/releases/latest)**.

## Какой файл выбрать

| Система | Файл |
|---|---|
| Windows 10/11 (64-bit) | `OpenGate-Setup-<версия>-x64.exe` |
| macOS 12+ (Intel и Apple Silicon) | `OpenGate-<версия>-macos.pkg` (или `.dmg`) |
| Linux (Debian/Ubuntu) | `opengate-vpn_<версия>_amd64.deb` |
| Linux (Fedora/RHEL) | `opengate-vpn-<версия>.x86_64.rpm` |
| Linux (Arch) | `opengate-vpn-<версия>-x86_64.pkg.tar.zst` |
| Android (большинство телефонов) | `OpenGate-<версия>-android-arm64-v8a.apk` |
| Android (старые 32-битные) | `OpenGate-<версия>-android-armeabi-v7a.apk` |

Контрольные суммы — в файле `SHA256SUMS` каждого релиза.

## Установка

- **Windows:** запустите установщик и следуйте шагам. Приложение обновляется само.
- **macOS:** откройте `.pkg`. Если macOS предупреждает о неизвестном разработчике — откройте файл через правую кнопку мыши → «Открыть». При первом обновлении macOS один раз попросит пароль администратора.
- **Linux:** установите пакет менеджером пакетов вашей системы.
- **Android:** разрешите установку из этого источника и откройте `.apk`.

После установки добавьте подписку из личного кабинета или Telegram-бота.
